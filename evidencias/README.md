# Evidencias

Cada tarea de `TASKS.md` que se marca `[x]` apunta a un archivo aquí.

**Nombre:** `<tarea>_<descripcion>.<ext>`, por ejemplo:

- `I1-T2_docker_compose_ps.txt`
- `I1-T3_verificar_entorno.txt`
- `I1-T7_contrato.json`
- `I2-T4_ejecucion_consultar_disponibilidad.png`
- `I3-T6_comprobante_RES-A7X9.pdf`

**Guardar la salida de un comando:**

```bash
bash scripts/verificar_entorno.sh > evidencias/I1-T3_verificar_entorno.txt 2>&1
```

**Capturas:** sin claves, Client Secret ni tokens visibles. Los correos de clientes de prueba se pueden dejar si son inventados.
